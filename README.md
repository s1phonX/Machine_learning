## Repository Overview

> **⚠️ Important:** Only run **`Financial_News_Stock_Prediction.ipynb`**. The other two notebooks were used to generate the supporting datasets and **do not need to be executed** unless you want to recreate the preprocessing pipeline.

### Main Project File

- **Financial_News_Stock_Prediction.ipynb**  
  The main notebook containing the complete machine learning pipeline, including feature engineering, model training (Logistic Regression, Random Forest, XGBoost, and MLP), model evaluation, and trading strategy backtesting.

### Supporting Notebooks (Preprocessing Only)

- **Clean_news.ipynb**  
  Cleans and preprocesses the raw financial news dataset to produce `news_clean.csv`.

- **Daily_Sentiment_Features.ipynb**  
  Uses the cleaned news data to generate daily FinBERT sentiment features and produces `daily_sentiment.csv`.

### Datasets

- **raw_market_data.csv**  
  Historical stock market data downloaded from Yahoo Finance for Apple (AAPL), Amazon (AMZN), Alphabet (GOOGL), and NVIDIA (NVDA).

- **news_clean.csv**  
  Cleaned financial news dataset generated by `Clean_news.ipynb`.

- **daily_sentiment.csv**  
  Daily aggregated FinBERT sentiment features generated by `Daily_Sentiment_Features.ipynb` and used by the main notebook for model training.

### Documentation

- **Financial_News_Stock_Prediction.pdf**  
  Final project report describing the methodology, experiments, results, discussion, and conclusions.
